## About this project

This repository is a beginner project for practicing Git version control and GitHub collaboration. The Python program asks for the user's name and displays a personalized greeting.

## Run the program

With Python installed, run this command from the repository folder:

```bash
python hello.py
```

Enter your name when prompted to see the greeting.
